# Art Heaven – Art Work by Neelofar Usman

An elegant, modern Next.js website showcasing original handcrafted pillows, acrylic paintings, and mixed media art collections by Pakistani artist **Neelofar Usman**.

## ✨ Features

- **Art Work by Neelofar Usman**: Hero showcase with dual-matted framed signature creations.
- **Curated Gallery with Pagination**: 9 artworks per page with PKR pricing and high-definition lightbox zoom.
- **Direct WhatsApp Purchasing**: One-click "Buy via WhatsApp" button that copies the artwork's title, price, and image link directly to WhatsApp (`+92 301 3100089`).
- **What I Do Section**: Showcasing hand-crafted 3D pillows, acrylic canvas art, and mixed-media creations with custom commission ordering.
- **Artist Spotlight**: Profile and philosophy of Neelofar Usman.
- **Responsive & Proportional**: Tuned with a refined 80% viewport scale, sticky navigation, and mobile drawer.

## 🚀 Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
